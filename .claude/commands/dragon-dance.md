# /dragon-dance — Record a lesson

Capture a problem → impact → new convention for future sessions.

## Steps

1. Ask (or infer from context): what was the problem? What was its impact? What's the new rule?
2. Add the lesson to `AGENTS.md` in the most relevant section (gotchas, forbidden, debugging table, etc.).
3. Append a one-line note to `docs/progress.md` under the current session entry: `Lesson: [rule]`.
4. Confirm: "Lesson recorded in AGENTS.md §[section]."

## Format for AGENTS.md additions

- **Gotcha:** add to §3 with the symptom, cause, and first-check pattern
- **Forbidden op:** add to §4 with the command and consequence
- **Debugging:** add a row to the §9 table

Do not add lessons that are already documented. Check before appending.
